# GigFlow 

GigFlow is a full-stack freelancing marketplace where clients can post jobs and freelancers can bid on them.  
Clients can review bids, hire a freelancer, and manage their jobs easily.  
The whole project is built with a clean flow so everything feels smooth and understandable.

This project is mainly focused on real-world logic, clean API flow, and practical full-stack implementation.

-----------------

##  Main Features

### Authentication
- User signup & login
- JWT based authentication
- Cookies used for secure sessions
- Protected routes for logged-in users

### client Side (job owner)
- Post a new jobs
- View all open jobs
- See all bids on a jobs
- Hire a bidder
- Move jobs automatically to Hired Freelancer when someone is hired

### Freelancer Side (bidder)
- View open jobs
- Place a bid on jobs
- View submitted bids
- See hired jobs if selected

### Dashboard
- Open jobs
- Submitted Bids
- Hired Jobs
- Real-time status update after hiring
- Clean UI with proper state management

## Project Flow 

1. Client creates a jobs  
2. Freelancers place bids on that job  
3. Client checks all bids  
4. Client hires one bidder  
5. That job moves to Hired Jobs  
6. Other bids are marked as rejected  
 

Everything is handled through proper backend logic and clean API calls.
